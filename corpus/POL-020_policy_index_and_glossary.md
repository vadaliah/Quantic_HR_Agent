The index lists every policy in force and the term used for each, so a reader can
find the document that governs a question. Where two policies touch the same
subject, the more specific policy governs.

## 2. Which Policy Governs

- Pay and deductions: POL-018. Expense limits: POL-005.
- Where work is done: POL-003. Working abroad: POL-004.
- When work is done: POL-019. Leave of absence: POL-008.
- Time off: POL-001 and POL-002. Benefits: POL-007.
- Equipment and devices: POL-010. Security controls: POL-006.
- Privacy and records: POL-017. Termination: POL-006 and POL-018.
- Conduct: POL-011. Complaints and escalation: POL-012.
- Hiring: POL-013. Performance and promotion: POL-014.
- Health and safety: POL-016. Travel: POL-015. Onboarding: POL-009 and POL-009A.

## 3. Glossary

| Term | Meaning |
| --- | --- |
| Accrual | Time off earned per completed month of service; see POL-001. |
| Band | The salary range attached to a role; see POL-018. |
| Blackout date | A date on which time off is restricted; see POL-002. |
| Buddy | A peer assigned to a new employee for the first 60 days; see POL-009A. |
| Carryover | Unused vacation moved into the next calendar year; see POL-001. |
| Core hours | 10:00 to 15:00 local time, when employees should be reachable; see POL-019. |
| Exempt | Not eligible for overtime pay; see POL-018. |
| PIP | Performance improvement plan; see POL-014. |
| Requisition | The approved request to hire for a role; see POL-013. |
| Stipend | The one-time home office allowance; see POL-005. |

## 4. Reading This Corpus

Every policy states the rule, the owner, and the consequence where one applies.
Where a policy refers to another, the reference is by document ID and section,
so a citation can be checked without reading the whole corpus.
